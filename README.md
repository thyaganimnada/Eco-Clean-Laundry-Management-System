# Eco-Clean Laundry Services - Management System

A C++ based console application designed to manage laundry services efficiently. This project was developed as the final assignment for the **Console System Fundamental Programming** module at campus.

## 🚀 Features

*   **User Authentication:** Secure login system (Username: `nimnada` / Password: `nimnada123`).
*   **Package Management:** Add, delete, and view available laundry service packages.
*   **Point of Sale (POS):** Calculate bills, manage quantities, and process sales with automated subtotals and totals.
*   **Sales History:** Track and view past sales records.
*   **File Handling:** Uses `packages.txt` and `sales_history.txt` to save and load data persistently.
*   **Company Details:** Displays contact and location information (Based in Mirissa, Matara).

*   **Core Concepts Used:**
